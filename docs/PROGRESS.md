# 진행상황

요구사항의 기준은 [설계 문서](DESIGN.md)입니다. 진행 상태와 검증 결과(테스트 수, 환경, 날짜)는 **이 문서에서만** 관리합니다.

`[x]`는 적힌 범위 안에서 완료, `[ ]`는 미완료입니다. 일부만 확인했다면 확인한 범위를 적고 상위 항목을 완료로 표시하지 않습니다.

## 현재 상태

- [x] 설계 문서와 화면 시안 작성.
- [ ] 1단계 엔진·CLI.

## 1. 엔진·CLI

- [ ] 프로젝트 골격, 의존성 고정, 테스트 환경.
- [ ] 입력 검증: CMYK·간격 정수, 범위, 칸 수·패치 수, 레이아웃 값.
- [ ] 두 채널 격자: 기준색 위치(짝수 포함), 증가 방향, 0/100 고정·경고·중복 유지.
- [ ] 시작·끝 보간: 정수 반올림(0.5 올림), 시작·끝 포함, 배치 순서.
- [ ] 레이아웃: 자동/지정 패치 크기, 분할(격자는 블록, 보간은 줄 단위), 장별 헤더, 라벨.
- [ ] 파일명, `_01` 분할 인덱스, `_v2` 충돌 회피, 덮어쓰기 금지.
- [ ] DeviceCMYK 단일 페이지 PDF 출력, 매니페스트, 역검사.
- [ ] CLI `grid`, `ramp`, `verify`.
- [ ] 콘솔 실행 파일 빌드.
- [ ] 설계 문서 9.1 자동 테스트 중 GUI 항목을 뺀 나머지 통과.

## 2. GUI

- [ ] 2단 구성: 보조 패널(고정 방식 탭, 스크롤 본문, 고정 하단), 미리보기.
- [ ] 방식별 설정 패널, CMYK 정수 입력과 즉시 오류 표시.
- [ ] 접이식 레이아웃 설정.
- [ ] 엔진 레이아웃 기반 미리보기, 장 넘김, 요약.
- [ ] 패치 선택과 다음 작업 입력값 채우기.
- [ ] 백그라운드 PDF 생성, 진행 상태, 완료·오류 안내.
- [ ] 미리보기와 PDF의 레이아웃 데이터 일치 테스트.

## 3. 배포

- [ ] 콘솔·GUI 두 실행 파일 빌드 설정.
- [ ] Windows에서 빌드.
- [ ] Python 없는 Windows PC에서 실행 확인.

## 4. 현장 확인

- [ ] 305×505mm 인쇄물의 CMYK 라벨 가독성.
- [ ] 실물 견본 비교 → 패치 선택 → 선택값으로 재생성 한 사이클.
