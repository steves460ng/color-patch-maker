### 1단계 검증 범위와 한계

- 검사: `.venv/bin/python -m pytest -q` — 리뷰 수정 후 323개 통과, 실패·건너뜀 없음.
- Linux 콘솔 빌드 성공. 빌드 결과로 두 방식 PDF·JSON 생성과 역검사를 확인했다.
- 최초 테스트 수집 중 문법 오류를 수정한 후 전체 테스트를 다시 실행했다.
- 직접 의존성은 ReportLab, pikepdf, pytest, PyInstaller이며 `requirements-dev.txt`는 전이 의존성도 고정한다. 전이 패키지는 이 도구들의 설치·실행에 필요하다.
- 자동 검증은 DeviceCMYK·좌표·용지·라벨·페이지 수, 파일 충돌과 실패 시 정리를 포함한다.
- 라벨은 제안값 최소 6pt로 제한한다. 무제한 축소를 막는 초기 하한이며, 실물 인쇄 가독성은 미확인이다. 하한 미달은 엔진에서 출력 전에 거부한다.
- GUI는 미구현이며 공유 레이아웃을 사용하는 GUI 테스트는 2단계에 수행한다.
- Windows 빌드·Python 없는 Windows PC 실행·실물 인쇄 확인은 수행하지 않았다.

### PR #1 리뷰 반영 — 2026-11-09

- 자동 크기는 계산한 행·열 전체를 한 장에 배치한다. 지정 크기의 칸 수 계산에는 1e-9mm 허용 오차를 적용했다.
- 라벨 최소 6pt를 엔진에서 검사하고 계산한 글자 크기를 PDF 출력에 전달한다. 최소값은 인쇄 검증 전의 제안이며, 기존 약 2~3.5pt 축소를 차단하기 위해 정했다.
- 보간 시작·끝은 `>`·`<`로 표시한다. 기본 PDF 글꼴에서 출력 가능한 기호로 영어 단어를 대체했다.
- JSON 읽기는 UTF-8을 명시하고 숫자가 아닌 mm 입력에는 항목명과 한글 해결 안내를 제공한다.
- Linux / Python 3.12.14: 전체 323개 테스트 통과. 격자 1~15열 × 1~15행과 보간 2~60개, 지정 크기의 정확한 맞춤, 최장 CMYK 라벨의 6pt 경계, 오류 시 파일 미생성을 포함한다.
- 격자 전 조합은 충분한 용지에서 PDF 한 장을 검증했다. 기본 용지에서는 읽기 가능한 경우 한 장, 15×15 등 6pt 미달은 오류로 거부한다. 자동 크기 요구와 라벨 하한을 함께 적용한 결과다.
- Linux 콘솔 실행 파일 재빌드 성공. 실행 파일로 9×9 격자·60개 보간의 단일 페이지 출력과 역검사, 10mm 패치 라벨 오류를 확인했다.
- `git diff --check` 통과. 1단계 완료 표시는 위 재검사 결과를 기준으로 유지한다. Windows·실물 인쇄·GUI는 아직 미검증이다.

### GUI 2-4 레이아웃 템플릿

- 기본 제공 값은 `engine/templates.py` 한 곳에 정의하고 `template_names()`, `template_values()`를 GUI·CLI가 공유한다. `validate_template()`는 기존 layout()의 1×1 레이아웃으로 색·방식 입력과 독립적으로 값을 검사·정규화한다. 실제 입력의 칸 수·라벨 제약은 기존 layout()이 그대로 검사한다. 계산·분할·출력 규칙 변경 없음.

- QSettings의 기존 저장소에 레이아웃 키만 JSON으로 저장한다. 덮어쓰기·삭제는 확인하고 취소하면 유지한다. 잘못된 항목은 개별적으로 건너뛰고 알림에 표시한다. CMYK·방식별 입력·저장 폴더는 템플릿 조작으로 바꾸지 않는다.

### GUI 2-5 출력 정리

- PDF와 미리보기에서 헤더를 제거하고 page_header() API도 제거했다. 기존 15mm 헤더 공간을 패치·라벨 배치에 사용한다. 라벨은 CMYK 한 줄과 기준색 ` *`·시작 ` >`·끝 ` <`만 표시하며 ID·장 정보는 매니페스트와 GUI에 유지한다.
- 라벨은 최대 7pt에서 폭에 맞춰 줄이고 엔진 상수 MIN_LABEL_PT=4.5 미만이면 출력 전에 거부한다. 미리보기는 동일한 label_font_pt와 문구를 사용하며 별도의 최소 표시 글자 크기 보정을 제거했다.
- 카드 템플릿은 85.6×54mm, 여백 2mm, 간격 1mm, 패치 18mm로 갱신했다. 한 장 4×2=8개, 7×7 격자 8 PDF·3×3 격자 2 PDF. C100 M100 Y100 K100 기준색도 출력·verify 통과.
- 매니페스트 키 구조는 유지하지만 헤더 없는 출력·ID 없는 라벨·허용 글자 크기라는 출력 계약을 구분하기 위해 schema_version을 2로 올렸다. 버전 2 역검사는 전체 텍스트 순서·개수·CMYK 기반 라벨 일치, Helvetica·폭에 맞춘 글자 크기·위치·검정색을 확인한다. 기존 패치·용지·단일 페이지 검사는 유지한다. 버전 1은 기존 검사를 유지하여 이전 파일을 계속 확인할 수 있다.
- 기존 테스트 수정 이유: 헤더 제거에 따라 여백 안쪽 상단 한계를 470→485mm, 세로 가용 높이를 450→465mm로 바꿨다. 최소 글자 크기 오류 기대값은 6→4.5pt, 경계 라벨은 ID 없는 문구로 갱신했다. 카드 값·분할 기대값은 새 규칙으로 바꾸고 이전 긴 라벨 오류 검사는 모든 채널 100의 성공 검사로 전환했다. 관련 없는 기존 검사는 유지했다.
- 새 검사는 4.5pt 경계 바로 위·아래(최장 기준색과 시작·끝 포함), 헤더/ID 없는 PDF 텍스트, ID·장 정보 보존, 글자 폭·크기, 헤더 제거 후 자동 크기, 첫 카드 8개 좌표, 추가 헤더·누락된 중복 라벨·글꼴·크기·위치·색 변조 거부를 확인한다. 버전 1 호환 및 변조 거부, 실제 Qt 그리기의 라벨 문구·크기와 엔진 값 일치도 확인했다.
