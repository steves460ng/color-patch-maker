### PR #1 리뷰 반영 — 2026-11-09

- 자동 크기는 계산한 행·열 전체를 한 장에 배치한다. 지정 크기의 칸 수 계산에는 1e-9mm 허용 오차를 적용했다.
- 라벨 최소 6pt를 엔진에서 검사하고 계산한 글자 크기를 PDF 출력에 전달한다. 최소값은 인쇄 검증 전의 제안이며, 기존 약 2~3.5pt 축소를 차단하기 위해 정했다.
- 보간 시작·끝은 `>`·`<`로 표시한다. 기본 PDF 글꼴에서 출력 가능한 기호로 영어 단어를 대체했다.
- JSON 읽기는 UTF-8을 명시하고 숫자가 아닌 mm 입력에는 항목명과 한글 해결 안내를 제공한다.
- Linux / Python 3.12.14: 전체 323개 테스트 통과. 격자 1~15열 × 1~15행과 보간 2~60개, 지정 크기의 정확한 맞춤, 최장 CMYK 라벨의 6pt 경계, 오류 시 파일 미생성을 포함한다.
- 격자 전 조합은 충분한 용지에서 PDF 한 장을 검증했다. 기본 용지에서는 읽기 가능한 경우 한 장, 15×15 등 6pt 미달은 오류로 거부한다. 자동 크기 요구와 라벨 하한을 함께 적용한 결과다.
- Linux 콘솔 실행 파일 재빌드 성공. 실행 파일로 9×9 격자·60개 보간의 단일 페이지 출력과 역검사, 10mm 패치 라벨 오류를 확인했다.
- `git diff --check` 통과. 1단계 완료 표시는 위 재검사 결과를 기준으로 유지한다. Windows·실물 인쇄·GUI는 아직 미검증이다.

### 탭 전환 레이아웃 안정화

- 두 방식 패널을 같은 스택 영역에 배치하고, 모든 페이지의 줄바꿈 높이를 반영해 공통 높이를 정한다. 입력은 위쪽에 정렬하고 격자 패널의 남는 공간은 아래에 둔다.
- 선택한 패치 버튼도 같은 스택 영역에서 전환한다. 레이아웃·선택한 패치·알림 위치가 탭에 따라 이동하지 않는다.
- `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q`: Linux / Python 3.12.14 / PySide6 6.8.3에서 339개 통과, 실패·건너뜀 없음.
- 1024×720, 1200×800, 1600×900과 레이아웃 접힘·펼침 상태에서 반복 탭 전환 시 공통 영역 및 첫 CMYK 입력 위치 불변을 검사했다. 기존 기본 화면 알림 가시성·오류 표시 테스트도 통과했다.
- `scripts/capture_gui.py`로 PNG 8장을 갱신했다. Windows 네이티브 실행은 이 환경에서 확인하지 못했으며 제공된 Windows 화면의 위치 이동을 회귀 조건으로 반영했다.

### GUI 2-2 엔진 연결 검증

- 기존 scalar 검사 함수를 재사용하는 `input_errors()`로 칸별 오류를 얻는다. `layout()`의 계산 규칙과 CLI 오류 메시지·종료 코드는 유지한다. `output_names()`와 `page_header()`는 엔진의 이름·헤더 형식을 화면에 제공하며 PDF 헤더도 같은 함수를 쓴다.
- `gui/controller.py`가 원문 입력·검사·레이아웃 호출과 표시를 연결한다. 미리보기는 반환된 패치 사각형을 왼쪽 아래 mm 좌표에서 화면 좌표로 변환하며 색 변환은 화면에만 사용한다.
- 오류 시 정상 미리보기를 지우고 안내로 대체한다. 칸별 메시지는 입력 아래에 표시하며 긴 메시지를 자르지 않고, 옆 입력칸의 상단 정렬을 유지한다.
- 장 넘김·요약·파일명·경고·패치 선택·선택값 적용·탭별 입력 유지 연결 완료. PDF 만들기·찾기는 계속 비활성이다.
- Linux / Python 3.12.14 / PySide6 6.8.3: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q` 전체 379개 통과(엔진 323 + GUI 56), 실패·건너뜀 없음. `pip check`, `git diff --check` 통과.
- 원문 오류 18개 조합, 다른 입력 오류, 레이아웃 오류, 기본/짝수/고정/보간/분할 데이터의 엔진 직접 호출 일치, 선택·적용·해제, 페이지 경계·입력 변경 복귀, Qt 없는 엔진을 검사했다.
- Chromium에서 시안의 입력 변경→미리보기→격자/보간 패치 클릭 흐름을 확인했다. 실제 GUI는 엔진의 6pt 하한을 적용하며 시안의 임시 출력 동작은 제공하지 않는다. Qt 외형과 별도 줄의 화면 색 안내를 유지한다. 설계 제안 변경 없음.
- `scripts/capture_gui.py`로 두 해상도에서 격자·고정 경고·오류·분할·보간·선택 12장을 저장하고 이전 자리 표시 캡처를 제거했다. Windows 네이티브 확인은 수행하지 않았다.
